## Hero

**Источник:** photo_2026-09-03_17-52-16.jpg (Midnight Maven / Showit)

**Взятые приёмы:**
- Полноэкранное фото с наложением крупного заголовка
- Контраст тёмного фона и бордового italic-акцента
- Editorial-иерархия: мелкий subtitle → крупный H1 → абзац → CTA → компактные факты

**Адаптация для MAGNUM:**
- Использована реальная фотография клуба вместо fashion-портретов
- Бордовый акцент на словах «ДОМ СПОРТИВНОГО» передаёт фирменный цвет
- Фишка как декоративный элемент вместо портретной сетки

**Не копировалось:** serif-шрифт, портретная сетка, точная палитра

**Mobile:** Заголовок разбит на строки с clamp(), факты в flex-wrap

## Как проходит вечер

**Источник:** photo_2026-09-03_17-52-17.jpg (Yanaan.design / сайт для фотографа)

**Взятые приёмы:**
- Светлая бумажная поверхность
- Тонкие горизонтальные линии-разделители
- Крупные номера 01–05 в приглушённом бордовом
- Асимметричное чередование изображений (слева/справа)

**Адаптация:** Журнальная сетка с 12 колонками, изображения чередуются по сторонам

**Не копировалось:** точная сетка, модульная журнальная раскладка

**Mobile:** Линейная стопка с номерами над каждым блоком

## Почему «Магнум» называют домом

**Источник:** photo_2026-09-03_17-52-17.jpg + photo_2026-09-03_17-52-19.jpg

**Взятые приёмы:**
- Bento-сетка разных пропорций (7+5, 4+4+4, 12)
- Overlay-текст поверх изображений
- Один текстовый блок (метро) без фото — контраст с фотографическими
- Тёмный фон для визуального контраста с предыдущей светлой секцией

**Не копировалось:** точные пропорции, красные плашки

**Mobile:** Вертикальная стопка, edge-to-edge изображения

## Галерея

**Источник:** photo_2026-09-03_17-52-19.jpg

**Взятые приёмы:**
- Асимметричная сетка (7+5, 4+4+4, 5+7)
- Разные aspect-ratio (landscape, portrait)
- Горизонтальный scroll-snap на мобильном

**Mobile:** Горизонтальная scroll-snap лента 75vw карточек

## Отзывы

**Источник:** photo_2026-09-03_17-52-19.jpg

**Взятые приёмы:**
- Горизонтальная scroll-лента с разной шириной карточек
- Крупные типографические кавычки
- Чередование бордового и полупрозрачного фона карточек
- Номера отзывов

**Mobile:** Snap-scroll, карточки 85vw

## FAQ
